## 翻译规则(必读)

### 1. 哨兵字符 —— 原样保留, 一字不差
- `[format]` `[/format]` `[color:red]` 等全部 `[...]` 标签: 只译标签**外面**的文字, 标签及被标签包裹的词按需译但**括号本身不动**
  例: `DO %ls IN [format][color:red]PROPERTY DAMAGE[/color][/format]` → 只把 PROPERTY DAMAGE 译为 财产破坏, 保留所有标签
- 格式化占位 `%s %d %ls {0} {1}` : 保留且**顺序不变**, 数量不变
- `\n` 换行符: 保留(可依中文习惯调整其位置, 但每行内容需自洽)
- `[image:xxx]` 图标引用: 原样保留

### 2. 风格
- 全大写 UI 目标/提示句 → 正常简体中文(不要保留全大写)
- 语气: 黑道圣徒3 是恶搞风格喜剧, 俚语/粗口按中文游戏习惯适度本地化, 不逐字直译
- HUD/目标/按钮文本**尽量短**(≤20 字, 参考英文长度), 字幕/描述可稍长
- 保留的英文专名(如人名品牌)首译时查 `terms_cand.md`, 有定名表则用表内译名

### 3. 术语
- `terms_cand.md` 中游戏世界观核心专名(帮派/地名/人物/节目名)请统一; 表外专名自行定名后追加到表

### 4. 提交前自检
- 每个 `zh` 里的 `[` `]` `%` `{` `}` `\n` 数量与 `en` 一致(哨兵完整)
- 无空翻译、无未翻译行(null)
