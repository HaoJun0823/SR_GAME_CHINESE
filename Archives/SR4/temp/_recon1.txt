; SR4R v1.3: 从 SR3R v7.5.2 移植, 适配 Saints Row IV (Steam / GOG / EPIC + 未知构建自解, L1/L2 双层特征码)
; dict_dir / origin_dir 均为可选 - 目录缺失时自动进入 font-only 模式(内置字符集)
; dict_dir   = 词典文件夹（相对本目录; 可选, 仅调试文本替换时使用）
; origin_dir = 联表文件夹（相对本目录; 可选）
; font_file  = 中文字体 TTF 文件名（相对本目录; 需 TrueType, 建议思源黑体 HW SC）
; dump_enabled = 是否收集未命中文本到 DumpText.dtxt（建议 1 用于首次测试）
; lang_early = 语言服务返回层整句替换（默认 1; 命中词典的完整句提前换中文）
; early_diag = 诊断日志（默认 1; 记录早期替换命中/Format 调用点归类, 验证完可设 0）
; subtitle_early = 字幕绘制入口整句替换（默认 1; 折行前换中文整句）
; charlist_file = 字符清单文件名（相对本目录; 可选, 缺省即 charlist.txt）
; text_dump = 可执行段落盘（0=关, 1=总是, auto=仅 hook 定位失败时, 默认 auto）
;       用途: Microsoft Store(MSIXVC)版的 exe 是密文, 离线取不到特征码;
;       注入进程内的 DLL 看到的是明文映像 —— 落盘后即可离线为新构建生成特征码。
;       本 DLL 正常时(8 条 hook 全命中)auto 不产生任何文件。
; exe = 强制指定游戏版本: auto / steam / gog / epic
;       默认 auto = 按 exe 的 PE 指纹(时间戳等)自动识别, 正常情况下无需设置。
;       [!] 不要依赖 exe 文件名来区分版本 —— EPIC 官方安装的可执行文件同样叫
;           sr_hv.exe（与 Steam 同名）, 按文件名判别会把 EPIC 误认成 Steam,
;           导致字形表读错、文字完全不显示。仅在自动识别失败时手工指定。
